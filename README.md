# albertusc.github.io

Personal portfolio site for GitHub Pages.

## Files

- `index.html` - Home and About
- `projects.html` - Projects portfolio
- `certifications.html` - Certifications and badges
- `experience.html` - Work experience and education
- `cv.html` - CV download hub with 4 role-focused versions
- `contact.html` - Contact links and CV hub link
- `pdf/` - Folder containing role-specific CV PDFs
- `styles.css` - Shared design system and layout
- `script.js` - Mobile nav interaction
